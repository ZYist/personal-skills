# 审查指定文件

## 前置条件
- 用户指定了一个或多个文件路径
- 已读 `rules/review-rules.md`

## 流程

### Step 1: 验证文件

1. 确认每个文件路径存在
2. 按 `rules/review-rules.md` 第六节排除规则过滤

**⚠️ 失败分支**：
- 文件不存在 → 告知用户具体哪个文件不存在，跳过
- 全部被排除 → 告知用户"所有指定文件均在排除范围内"，终止

### Step 2: 读取文件内容

读取每个文件的完整内容。

### Step 3: 按维度审查

执行 `workflows/review-diff.md` Step 3 的相同检查清单。
区别：没有 diff 作为变更提示，需要对整个文件进行全面审查。

### Step 4: 生成报告

按 `rules/review-rules.md` 规定的格式生成报告。

### Step 5: 输出报告

向用户展示报告并询问是否需要修复建议。
