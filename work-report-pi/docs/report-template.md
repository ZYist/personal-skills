# 日报模板(固定:"重点+成果"式)

生成日报时按此格式组织。**模板结构可复用,内容不预制**——每次从当天的真实数据生成。

## 格式

```markdown
**今日工作(YYYY-MM-DD):**
1. **[成果型条目]**:一句话(来源:钉钉/本机)
2. **[...]**:一句话
...
**日程**:会议列表(名称、时间、参会人)
**待办状态**:新开 N / 完成 N(如有数据)
```

## 条目分类与排序

按成果优先排序:

1. **成果/结论**(定位到根因、确认了方案、完成了搭建)→ 放最前
2. **推进中的工作**(联调中、测试中、准备验证)
3. **沟通协调**(会议、确认计划、需求对齐)→ 靠后
4. **环境/工具**(搭环境、装软件)→ 可合并为一条或并入相关条目

## 写法规则

- 每条一行,动宾结构(动词开头):"定位 92 x11perf 卡死根因"、"确认 jh920 降功耗回归测试计划"
- 带成果/结论的加括号补充(如"调试间现场定位到根因")
- 不编造:数据里没有的不写
- 去重:本机+钉钉同一件事合并为一条

## 示例(仅作格式参考,内容不沿用)

```markdown
**今日工作(2026-08-05):**
1. **定位 92 x11perf 卡死问题**:复现确认、核对固件版本,调试间现场定位到根因
2. **联调 2D 卡死**:AXI 调频逻辑修改后频率回落仍卡死,计划飞腾 2000 平台验证
3. **获取 jm7200gop(GOP 驱动)源码**,搭建虚拟机 UEFI 开发环境
4. **确认 jh920 降功耗 2.1.0 固件回归测试计划**
**日程**:vbios 需求对齐(14:00-15:00,A304)
**待办状态**:进行中 8 条(固件维护类)
```
