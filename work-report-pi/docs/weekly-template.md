# 周报模板(固定)

结构对应钉钉"周报"模板字段(本周完成工作/本周工作总结/下周工作计划/需协调与帮助)。**结构可复用,内容每次从真实数据生成。**

## 格式

```markdown
**本周完成工作(YYYY-MM-DD ~ YYYY-MM-DD):**
1. **[成果条目]**:一句话(含日期/来源)
2. **[...]**:一句话

**本周工作总结:**
- 跨天趋势/共性问题/方法论(1-3 条)

**下周工作计划:**
1. **[未完成任务]**:下一步动作
2. **[...]**: ...

**需协调与帮助:**
- 需要他人配合/权限/资源的事项(无则写"无")
```

## 生成规则

### 本周完成工作
- 每天的工作条目按天汇总,合并跨天重复任务
- 成果型优先(定位根因 > 完成交付 > 推进中)
- 每条标注日期(如"8/5 定位 92 x11perf 卡死根因")

### 本周工作总结
- 找跨天共性(如"本周 3 个问题都是 2D 频率回落引发")
- 或方法论沉淀(如"建立虚拟机 UEFI 开发环境,后续固件问题可在本地复现")
- 没有共性就写本周整体进展一句话,不硬凑

### 下周工作计划
- 从未完成待办 + 进行中任务推导
- 明确写下一步动作,不写空话

### 需协调与帮助
- 从对话里找"需要别人提供/确认/配合"的内容
- 无则写"无"

## 示例(仅作格式参考,内容不沿用)

```markdown
**本周完成工作(2026-07-28 ~ 2026-08-01):**
1. **8/1 定位 x11perf 卡死根因**:复现确认、调试间现场定位
2. **7/30 确认 jh920 降功耗回归测试计划**
...

**本周工作总结:**

- 搭建虚拟机 UEFI 开发环境,支持本地复现与驱动开发

**下周工作计划:**
1. 在飞腾 2000 平台验证 2D 卡死修复
2. 启动 jm7200gop 驱动 UEFI 移植

**需协调与帮助:**
- 需杜豪男提供 jm7200gop 完整工程(当前仅源码)
```
